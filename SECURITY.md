# Security Policy / 安全政策

## 中文

当前只支持 `master` 分支。

如果你发现安全问题，请通过私信联系仓库所有者进行私下报告。

请不要在公开 issue 中提交真实凭据、会话值、Cookie 或任何敏感信息。

这个仓库只应包含公开前端内容。私有运行文件、备份文件和本地构建产物不应进入公开仓库。

## English

Only the current `master` branch is supported.

If you discover a security issue, please report it privately to the repository owner.

Do not include live credentials, session values, cookies, or any sensitive information in public issues.

This repository should only contain public frontend content. Private runtime files, backups, and local build artifacts should not be included in the public repository.
